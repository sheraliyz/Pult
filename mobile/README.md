# Pult — Android

Pult’ning telefon versiyasi (Flutter). Imkoniyatlar, o‘rnatish va yig‘ish bo‘yicha: [asosiy README](../README.md).

- `lib/core` — SSH ulanish, qayta ulanish, tmux sessiyalar, SFTP uzatish, serverdagi fayl amallari.
- `lib/ui` — ekranlar.
- `test/core_test.dart` — yadro testlari (`dev/mock-server.js` kerak), `test/screens_test.dart` — ekran rasmlari.
